# Build a Premium Alumni Management Portal

Build a modern, premium, responsive **Alumni Management Portal** for a college/university.

The website should feel like a real SaaS/product platform, not a basic student project. Keep the interface **simple, elegant, professional, spacious, and easy to use**, while providing many useful features.

---

## 1. Product Name

Use the name:

**AlumniConnect**

Tagline:

**Connect. Inspire. Grow.**

The branding should be easy to change later.

---

# 2. Main Goal

The platform should create a digital community connecting:

* College administrators
* Alumni
* Current students
* Faculty
* Mentors

The system should allow the college to maintain alumni records, communicate with alumni, organize events, provide career opportunities, support mentorship, and build a strong alumni network.

implementation plan:
# AlumniConnect — first milestone

A premium alumni portal for a university, in the "Soft pastel glass" look you picked: pale lilac paper background, soft glass cards, pastel mint/sky/peach/lilac accents, Bricolage Grotesque headings with Fraunces numerals.

The full brief is very large (50 sections). This plan delivers a real, working foundation first — the public landing page, accounts with four roles, and the three dashboards — then adds the rest module by module.

## Note on the technology

The brief asks for Python/Flask + MySQL. That combination can't run here. Instead this project uses Lovable's built-in backend (Postgres database, secure logins, server-side code) which gives the same result: real accounts, real records, real permissions. Everything is one project you can run and publish from here.

## Milestone 1 — what gets built now

### Landing page (`/`)
- Glass nav bar: AlumniConnect logo, Alumni / Events / Jobs / Mentorship / Stories / About, Login and Join the Community.
- Hero: "Your college network doesn't end at graduation." with the brief's subheading, Explore Alumni + Join AlumniConnect buttons, and the alumni "boarding pass" card from the chosen direction.
- Animated statistics band (5,000+ alumni, 1,200+ companies, 350+ mentors, 150+ events, 800+ jobs) with numbers counting up.
- Six feature cards, alumni showcase grid, upcoming events + success story split, dark CTA panel, footer.
- Branding (name, tagline, university name, logo mark) kept in one small settings file so it's easy to change later.

### Accounts and roles
- Sign up, log in, log out, forgot password, password reset.
- Four roles: Admin, Alumni, Student, Faculty, stored in a separate roles table (never on the profile) so roles can't be tampered with.
- Private pages are blocked for signed-out visitors; each role only sees its own dashboard and data.
- New alumni sign-ups start as "Pending verification" and stay out of the public directory until an admin approves.

### Three dashboards
- **Student**: "Welcome back, [name]", cards for recommended alumni, recommended jobs, upcoming events, pending mentorship requests, saved opportunities; quick actions row.
- **Alumni**: profile views, connections, mentorship requests, events joined, jobs posted; quick actions (update profile, become a mentor, post a job, create event, share story).
- **Admin**: totals (alumni, active alumni, students, faculty, events, jobs, mentors, pending approvals), charts for alumni by graduation year / department / industry / location and monthly registrations, plus a recent-activity feed.
- Shared shell: sidebar on desktop, compact bottom navigation on mobile.

### Data and demo content
Database tables for users/profiles, roles, departments, alumni details, education, experience, skills, events + registrations, jobs, mentorship requests, connections, posts, notifications, success stories, saved items — with proper relationships and per-user access rules.

Seeded with realistic demo content: 30+ alumni, 10+ students, 5 faculty, 10 companies, 10 jobs, 8 events, 15 community posts, 10 success stories, 10 mentors, so every dashboard looks alive immediately.

### Reusable pieces
Buttons, cards, avatars, badges, search, filters, tables, modals, toasts, skeleton loaders, empty states ("No saved jobs yet"), friendly error messages, accessible labels and focus states.

## Technical notes
- TanStack Start (React) with file-based routes; Tailwind v4 tokens taken from the chosen direction into `src/styles.css`; fonts loaded via the root route.
- Lovable Cloud (Postgres + auth) enabled first; server functions for all reads/writes; row-level security on every table; roles resolved through a `has_role` security-definer function.
- Protected pages live under an authenticated layout; public pages stay server-rendered with their own page titles and descriptions.
- Demo data inserted as part of the database migration.
- A README with setup and environment notes is included at the end of milestone 1.
